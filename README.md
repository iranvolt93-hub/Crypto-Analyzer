# Crypto Watchlist Telegram Bot

ربات سبک تحلیل بازار کریپتو با واچ‌لیست شخصی برای هر کاربر.

## امکانات
- افزودن ارز با نماد BTC / ZEC / SOL و ...
- ذخیره واچ‌لیست در SQLite
- تحلیل EMA20/50/200، RSI، MACD، ADX، ATR و مومنتوم
- قدرت روند و احتمال مدل به صورت جداگانه
- سیگنال BUY / SELL / WAIT
- محدوده ورود تحلیلی، حد ضرر و اهداف بر اساس ATR
- انتخاب تایم‌فریم 15m / 1h / 4h / 1d
- هشدار تغییر سیگنال
- دیتابیس پایدار
- مناسب GitHub و Railway
- بدون اجرای معامله خودکار

## راه‌اندازی Railway

1. این پروژه را در GitHub قرار دهید.
2. در Railway یک Service از GitHub بسازید.
3. Variable زیر را بسازید:

`TELEGRAM_BOT_TOKEN=توکن ربات BotFather`

اختیاری:
- `DB_PATH=crypto_bot.db`
- `ALERT_SCAN_SECONDS=300`
- `MAX_WATCHLIST=100`
- `HTTP_TIMEOUT=15`

4. Deploy را انجام دهید.
5. Logs را بررسی کنید. باید پیام `Starting bot...` و سپس `Bot initialized` دیده شود.

## نکته مهم درباره SQLite در Railway
SQLite داخل فایل سرویس ذخیره می‌شود. برای حفظ دائمی دیتابیس هنگام تعویض/حذف محیط Railway، یک Volume دائمی به سرویس متصل کنید و `DB_PATH` را روی مسیر Volume قرار دهید؛ مثلاً:

`/data/crypto_bot.db`

بدون Volume، خود کد درست است ولی ماندگاری فایل دیتابیس به محیط استقرار وابسته خواهد بود.

## منبع داده
نسخه پایه از Binance Spot API و جفت‌های USDT استفاده می‌کند. ارزهایی که جفت USDT قابل معامله داشته باشند قابل افزودن هستند.

## امنیت
توکن ربات را داخل GitHub نگذارید. فقط در Railway Variables قرار دهید.
